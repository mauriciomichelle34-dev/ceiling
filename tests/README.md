# 测试

安装项目依赖后，从项目根目录运行：

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

94 项测试覆盖坐标方向、PLC 数据传输、接图自动处理、相机接口及 PLC 到位自动拍照。包括默认 v4 与旧 v3 权重的实际加载和预测检查，以及红外定位、无红外反光保护、位移、多点拒绝、局部像素保护和保存结果过滤检查。测试使用模拟相机、内存中的 PLC 替身和本机回环 S7 服务，不访问真实设备。HTTP 测试需要允许 Python 访问本机临时端口。

`s7_test_server.py` 仅为测试补充 python-snap7 3.3.0 模拟服务端的位写入语义，不修改生产客户端。模拟测试不能替代真实相机、图像标定及 PLC 动作时序的联调。


## 螺丝唯一原点（v21）

当前共 101 项测试。新增螺丝原点与 CSV/PLC 10 倍换算的一致性、修改原点只平移 XY、培养皿移动时原点和毫米比例保持固定、无原点和旧培养皿中心规划在通信前被拒绝，以及旧自动参数不会继续运行。网页实测覆盖点选、保存、同尺寸图片复用、修改原点后发送按钮锁定；本次实拍验证只预览，未写入真实 PLC。

## 上传后自动排布（v25）

## CH1 拍照补光（v26）

134 项 Python 测试通过，前端原有 3 项行为测试通过。新增测试覆盖 DCS3 指令与校验、分段响应、只读亮度查询、设置持久化、开灯与取图时序、拍照异常后关灯、关灯重连重试、关灯失败时阻止后续处理、重复请求不重复闪灯，以及自动流程运行期间的设置锁定。自动测试使用模拟光源，不控制真实设备。

现场验证使用 CH1、亮度 170/255：网页拍照成功，补光记录约 375 ms，收到关灯确认，用户确认灯闪后熄灭。该照片未通过培养皿边缘检测，未生成坐标；自动流程保持关闭，未向真实 PLC 下发数据。
