# 菌丝体分割与取样规划

当前应用版本为 v28，更新范围见 [v28 更新说明](RELEASE_V28.md)：每张照片自动定位右下角银色螺丝中心作为坐标原点，定位失败时沿用同画幅最近一次成功位置并提示；首次尚无成功记录时停止生成坐标。说明见 [自动螺丝原点](自动螺丝原点说明.md)。已通过 151 项 Python 测试和 13 项前端行为测试；默认 v4 与 v3 回退权重保持不变。

拍照补光已接入：DCS3 CH1 通过 `192.168.6.15:9232` 控制。网页拍照与 PLC 自动拍照都会在取图时开灯、取到图像后关灯；亮度和补光开关可在相机区域保存，操作见 `拍照补光使用说明.md`。

v28 增加空闲关灯处理：启动程序、每次新拍照访问 SDK 前、保存停用补光设置及正常退出时，主动向 CH1 发送关灯指令。相机在准备阶段失败时也不会保留先前的持续开灯状态；不能确认关灯时阻止本次拍照。

支持直接上传相机原始 BMP，以及 JPG、PNG；单张最多 100 MB、2500 万像素。无需先转换或缩小相机照片。

取样圆默认直径 10 mm、边缘间隙 1 mm。上传或网页拍照后自动生成取样排布；需要调整时修改参数并重新生成。取样参数不再提供统一 Z 输入，Z 轴由 PLC 控制。未启动自动流程时仅排布，测试时手动点击“仅覆盖坐标（测试）”；启动自动流程后才由后台识别、排布并下发。

坐标原点使用本张照片自动定位的银色螺丝中心，适用 5472 × 3648 画幅。程序不再读取旧的 `(4045, 3010)` 固定像素配置。X 向左为正、Y 向上为正；网页、CSV/JSON 导出与 PLC 下发沿用本张照片的原点，PLC 按 1 mm = 10 换算。培养皿中心仅用于识别与尺寸标定。旧结果需要重新识别和生成坐标，不会自动把另一张照片的原点套到已有规划上。

无人循环已接入：在“图片来源”选择“全自动 · PLC 到位后自动拍照”，程序监听 DBX4.2，到位后自动拍照、识别、划圈并下发数量和坐标。PLC 完成设备动作并将 DBX4.0、DBX4.2 都复位后，再等待下一轮。首次设置和完整时序见 `全自动无人循环使用说明.md`。

本文件夹为相机拍照、自动识别与 PLC 下发版。双击 `Start_Local_App.cmd`，打开 `http://127.0.0.1:8766/`。左侧“海康相机拍照”支持通过 MVS SDK 搜索、连接和软件拍照，操作见 `相机拍照使用说明.md`。只测试坐标写入时选择“坐标覆盖测试”，或使用“仅覆盖坐标（测试）”按钮；需要通知 PLC 执行动作时选择“联动执行”。固定参数和接图入口见 `自动流程使用说明.md`，覆盖测试操作见 `坐标覆盖测试说明.md`，地址表见 `PLC使用说明.md`。

下载 ZIP 并解压，用 VS Code 打开其中的 `ceiling.code-workspace` 文件。电脑需安装 Python 3.10 或更新版本（推荐 3.11），VS Code 安装 Python 扩展。

在“运行和调试”中选择“启动菌丝体网页”，按 Ctrl+F5。也可以在终端运行：

```bash
python start.py
```

Windows 可以双击 `Start_Local_App.cmd`。首次启动会自动准备依赖，需要联网并等待下载；之后直接启动。模型权重已包含，无需训练。默认安装 CPU 依赖，已有可用 GPU 环境也能运行。

默认使用相机适配权重 `mycelium_v4_full16.pt`，图片按比例缩放补边后推理，输出恢复到原图尺寸。此模型使用确认标注的全部 16 张照片、128 组旋转/翻转输入训练，训练图平均 Dice 为 0.9504；这是拟合成绩，不能作为新照片准确率。第一阶段留出试验平均 Dice 仅从 0.6024 升至 0.6564，偏黄色菌丝仍严重漏检。完整记录见 [模型更新与评估](MODEL_V4.md)。应用版本 19 已在网页分割后增加传感器红外亮点自动排除，详见 [红外排除使用说明](红外排除使用说明.md)。培养皿检测仍沿用现有实现，检测失败时会停止输出。旧 v3 已保留，切回时关闭当前服务，再运行 `python start.py --model mycelium_v3.pt`；也可用 `python start.py --model mycelium_v2.pt` 对照更早版本。

只生成模型原始分割结果，可运行 `python predict.py "照片路径"`；结果保存在 `results` 文件夹。

“培养资料”可填写菌丝种类、培养开始时间，同一批照片共用并保存在当前浏览器；新批次可点击“重置培养资料”。培养资料、菌丝面积及取样覆盖率集中显示在培养皿预览上方。

完整原图直接用于推理，上传后自动寻找培养皿内边缘并画出白色虚线，仅在边界内显示菌丝结果、计算面积、生成取样和导出标注。青色标定圆仍用于换算实际尺寸；请核对两条边界。内外边缘无法可靠区分时会停止输出，请使用完整、清晰的俯视照片重试。

通过启动文件打开的网页位于 <http://127.0.0.1:8766/>。上传照片后，后台按固定 90 mm 培养皿自动标定，菌丝区域会播放约 0.8 秒的光边与覆盖动画，结束后显示菌丝体面积（mm²）及占培养皿面积的百分比；每张照片独立自动测算，无需手动填写或保存标定。也可继续生成取样点。关闭启动终端可停止服务。PLC 接口发送 X、Y 和数量；包含 Z 深度的通用取样动作接口仍为预览。自动分割结果需要人工核对。
